# How to set up RayGrid on your PC

RayGrid is the remote access client being built by the Ghost developers, for reaching your home computer from outside. It is in development and marked as Coming Soon.

## Status

- RayGrid is not released yet.
- It replaces the earlier WarpDesk prototype.

## Planned workflow

1. Clone the RayGrid host project and follow its `README.md`.
2. Apply any code or changes you want to fit your setup.
3. Configure your local build per the `README.md`.
4. Run the app, then forward or mirror the server port.

## Server port handling

- You can run your own TURN server, but Cloudflare is recommended.
- Cloudflare Tunneling exposes your outbound only server port.
- Cloudflare also provides a TURN server to hold the connection.
- These features are free. The `README.md` will have the real steps at release.
