# How to set up a remote proxy server

This is an advanced feature for users who want traffic routed through an extra proxy layer.

## Requirements

- A running proxy endpoint.
- Supported protocol: HTTP, SOCKS4, or SOCKS5.

## Configuration steps

1. Open Settings (or Quick Browsing Settings).
2. Set Proxy Routing to Remote Proxy Server.
3. Pick the proxy type: HTTP, SOCKS4, or SOCKS5.
4. Enter your proxy endpoint.

## Notes

- Wrong protocol and endpoint combos will fail to connect.
- Test your proxy endpoint outside Ghost first when troubleshooting.
