# Customize

Ghost gives you a lot of control over how it looks and behaves.

## What you can customize

- Themes, including presets and fully custom themes.
- Global font, padding, and border radius.
- Tab cloaking (title and icon) for privacy.
- Backgrounds, including animated ones.
- Raw global CSS through the CSS editor.
- Sidebar buttons through the Sidebar Editor.

## How to customize

- Open Settings.
- Go to Customize.
- Pick a theme and font.
- Tweak the other sections to match how you browse.

## For self-hosted instances

- You can inject custom global CSS to restyle your whole deployment.
- Changes apply live as soon as you hit Apply.
