# Access my home computer with RayGrid

RayGrid is Ghost's upcoming remote desktop experience. It is not available yet.

## Status

- RayGrid is still in development and shows as Coming Soon on the Remote Access page.
- Once released, it will let you reach a host PC from the browser.
- Until then, use Browser.lol from the Remote Access page for a cloud VM.

## What you will need later

- A RayGrid host running on the machine you want to reach.
- The host connection URL.
- Your RayGrid login credentials.
