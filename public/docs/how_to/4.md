# Fix common issues

Use this guide to figure out common proxy and transport errors in Ghost.

## LibCurl errors

- SSL connect error 7: the Wisp server is currently unavailable.
- SSL connect error 35: the destination site may not exist or is unreachable.
- SSL connect error 60: the destination site certificate is malformed, expired, or invalid.

## Epoxy errors

- WebSocket failed to open: the Wisp server is currently unavailable.
- Stream creation failed due to an unreachable destination: the destination site may not exist or is unreachable.

## Scramjet and BareMux errors

- There are no bare clients: the request fired before workers finished registering. Refresh the page and try again.
- Attempted to fetch from same origin: Scramjet tried to fetch the host URL directly. Some sites with odd refresh behavior trigger this. Go back and retry navigation.

## One site fails while others load

- This is usually not Ghost. It means that specific origin is failing.
- Common causes: the site blocks proxy or datacenter traffic, its certificate chain is incomplete, or your wisp server DNS sinkholes the domain.
- Try a different wisp server first. If it still fails everywhere, the site itself is blocking proxied traffic.

## General recovery steps

- Refresh the tab. Ghost silently retries stalled loads on its own, but a manual refresh never hurts.
- Switch transport or backend in Settings.
- Make sure your selected Wisp server is online.
- Confirm the destination site loads from your network without the proxy.
