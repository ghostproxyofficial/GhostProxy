# Import and export my data

Ghost lets you back up and restore everything locally.

## Export data

- Open Settings.
- Go to Data.
- Select Export Data.
- Save the generated `.ghost` backup file somewhere safe.

## Import data

- Open Settings.
- Go to Data.
- Select Import Data.
- Pick a `.ghost` file you exported before.

## Extra backup option

- In the Profile Manager, you can also export profile related data for later restore.

Exports never leave your device unless you move the file yourself.
