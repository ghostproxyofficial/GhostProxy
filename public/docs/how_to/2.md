# Delete my data

Ghost gives you full control of your local data.

## Delete all data

- Open Settings.
- Go to Data.
- Choose Delete Data.

This is permanent and cannot be undone, so export a backup first if you want to keep anything.

## Delete profile specific data

- Open the Profile Manager.
- Remove the specific profile you no longer need.

All Ghost user data stays local unless you explicitly turn on a future cloud feature.
