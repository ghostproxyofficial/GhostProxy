# General info

Ghost is a browser style web client focused on accessibility, customization, and user side control.

## Privacy and data

- Ghost stores your data locally by default.
- You can wipe all local data from Settings at any time.
- You can export and import data using Ghost backup files.

## Reliability

- Whether a site loads depends on your backend, transport, wisp server, and network.
- Some sites fail because of upstream blocks, bad certificates, or temporary downtime.
- If one site fails everywhere while others load fine, try a different wisp server before assuming Ghost is broken.
