# How to use Ghost

Ghost works like a normal browser, with tabs, an address bar, and bookmarks. Everything you open runs through the proxy so sites load inside Ghost.

## Core features

- Multi-tab browsing with quick switching and tab persistence.
- Search and URL navigation through the omnibox.
- Built-in sections for games, TV, music, AI, notes, and tools.
- Configurable proxy backends and transport options.
- Privacy controls like user agent spoofing and browser identity.

## Basic workflow

- Open or create a tab.
- Type a URL or search query in the omnibox.
- Use the sidebar buttons to jump to Ghost sections fast.
- Open Settings to tune theme, behavior, and performance.

## Browser controls

- Back, forward, and reload live in the top bar.
- Bookmark pages from the top bar.
- Per-site controls (ad block, popup block, download block) are available where applicable.

## Tips for new users

- Pick your search engine and backend in Settings.
- Turn on Performance Mode if your device struggles.
- Export your data now and then to keep local backups.
